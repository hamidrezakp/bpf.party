تا اینجا، هر تمرین از یک برنامه eBPF استفاده کرده است. اما اگر بخواهیم اطلاعات را بین رویدادهای مختلف همبسته کنیم چه؟

مثلاً: وقتی یک فرایند **شروع** می‌شود، نام آن را می‌دانیم. وقتی **خارج** می‌شود، کد خروج آن را می‌دانیم. اگر بخواهیم **نام** فرایندهایی را که با کد خاصی خارج می‌شوند بفهمیم چه؟

## چند برنامه eBPF

می‌توانید **چند برنامه در یک فایل** تعریف کنید؛ هر کدام به رویدادهای متفاوتی متصل می‌شوند.

هر برنامه مستقل است و وقتی رویداد خودش فعال شود اجرا می‌شود.

یک مورد رایج که به چند برنامه نیاز دارد، جفت رویداد `entry`+`exit` است.

در **ورود**، ورودی را داریم (آرگومان‌ها، اطلاعات فرایند).

```c
SEC("tracepoint/sched/sched_process_exec")
int on_process_start(struct trace_event_raw_sched_process_exec *ctx) {
    // When the process starts execution
}
```

در **خروج**، خروجی را داریم (مقادیر بازگشتی، کدهای خروج).

```c
SEC("tracepoint/syscalls/sys_enter_exit")
int on_process_exit(struct trace_event_raw_sys_enter *ctx) {
    // When the process calls exit (program termination)
    // ctx->args[0] contains the exit code
}
```

برای همبسته‌کردن هر دو رویداد، باید داده را بین فراخوانی‌های برنامه نگه داریم.

## نگه‌داری وضعیت

**Mapها** ساختارهای داده‌ای هستند که بین فراخوانی‌های برنامه eBPF باقی می‌مانند.

در eBPF، [انواع زیادی](https://docs.ebpf.io/linux/map-type/) map وجود دارد. در این تمرین از hash map (ذخیره کلید-مقدار) استفاده می‌کنیم.

استفاده از map ساده است. ابتدا یک struct با این ماکروهای `__uint`/`__type` تعریف کنید.

```c
struct {
    __uint(type, BPF_MAP_TYPE_HASH);
    __uint(max_entries, 1024);
    __type(key, u64);         // What you use to look up
    __type(value, char[16]);  // What you store
} my_map SEC(".maps");
```

برای ذخیره‌کردن، اشاره‌گری به داده را می‌دهید که کپی می‌شود:
```c
u64 key = 12345;
char value[16] = "hello";
bpf_map_update_elem(&my_map, &key, value, BPF_ANY);
```

برای گرفتن اشاره‌گر به مقدار:
```c
char *stored = bpf_map_lookup_elem(&my_map, &key);
if (!stored) { // Key not found
    return 0;
}
// Use `stored` (it's a pointer to the char[16] array)
```

برای حذف یک ورودی از map:
```c
bpf_map_delete_elem(&my_map, &key);
```

## چالش

یک برنامه به نام `exit_with_code` اجرا می‌شود و خارج می‌شود. کد خروج آن را با `SUBMIT_NUM(code)` ارسال کنید.

کد اولیه بیشتر منطق را از قبل دارد؛ این فصل در نهایت مقدمه است.
