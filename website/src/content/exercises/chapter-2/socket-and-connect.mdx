مثل `open()` و `read()`، اتصال‌های شبکه هم یک تلاش (ورود) و یک نتیجه (خروج) دارند. برای همبسته‌کردن این رویدادها، در ورود داده را ذخیره می‌کنیم و در خروج آن را می‌گیریم.

## syscall connect

```c
int connect(int sockfd, const struct sockaddr *addr, socklen_t addrlen);
```

در **ورود** (`sys_enter_connect`):
- `ctx->args[0]` = file descriptor سوکت
- `ctx->args[1]` = اشاره‌گر به ساختار `sockaddr` (user space)

در **خروج** (`sys_exit_connect`):
- `ctx->ret == 0` → اتصال موفق بود
- `ctx->ret < 0` → اتصال ناموفق بود (مقدار errno)

## خواندن ساختار sockaddr

اشاره‌گر `addr` در `ctx->args[1]` به حافظه user space اشاره می‌کند. برای کپی امن باید از `bpf_probe_read_user()` استفاده کنید:

```c
struct sockaddr_in addr;
bpf_probe_read_user(&addr, sizeof(addr), (void *)ctx->args[1]);
```

برای اتصال‌های IPv4 (`sin_family == 2`):

```c
struct sockaddr_in {
    u16 sin_family;  // AF_INET = 2
    u16 sin_port;    // Port (network byte order!)
    u32 sin_addr;    // IP address
    char __pad[8];
};
```

پورت و IP در **ترتیب بایت شبکه** ([big-endian](https://en.wikipedia.org/wiki/Endianness)) هستند. با helper به ترتیب بایت host تبدیل کنید:

```c
u16 port = bpf_ntohs(addr.sin_port);
```

## چالش

یک برنامه سعی می‌کند به چند پورت متصل شود. بیشتر اتصال‌ها ناموفق‌اند، اما یکی موفق می‌شود. **پورت اتصال موفق را ارسال کنید.**

### وظیفه شما:
1. در ورود `connect`: ساختار `sockaddr_in` را بخوانید و پورت را در یک map موقت ذخیره کنید
2. در خروج `connect`: بررسی کنید اتصال موفق بوده (`ret == 0`)، سپس پورت را ارسال کنید
