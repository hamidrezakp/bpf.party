در تمرین قبلی، یاد گرفتیم چطور با mapها داده را بین چند برنامه eBPF به اشتراک بگذاریم.

حالا این را برای گرفتن داده از بافرهای syscall به کار می‌بریم. syscallها دو رویداد tracepoint دارند: `enter` (قبل از شروع) و `exit` (بعد از پایان). باید داده را بین هر دو همبسته کنیم.

## syscall read

با نگاه به [syscall read](https://man7.org/linux/man-pages/man2/read.2.html):

```c
ssize_t read(int fd, void *buf, size_t count);
```

اگر به `sys_enter_read` و `sys_exit_read` متصل شویم:

- در **ورود**: به آرگومان‌ها دسترسی داریم، اما بافر هنوز خالی است.
- در **خروج**: بافر با داده پر شده، اما فقط به مقدار بازگشتی دسترسی داریم.

برای همبسته‌کردن هر دو، در ورود اشاره‌گر بافر را با map ذخیره می‌کنیم، سپس در خروج بافر پرشده را می‌خوانیم.

## ذخیره آدرس بافر در ورود

ابتدا باید وقتی syscall شروع می‌شود، اشاره‌گر بافر را ذخیره کنیم. آدرس بافر در `ctx->args[1]` است.

این آدرس را در یک map ذخیره می‌کنیم و PID را به‌عنوان کلید استفاده می‌کنیم تا بعداً بتوانیم آن را پیدا کنیم:

```c
u64 buf_addr = ctx->args[1];
bpf_map_update_elem(&read_buffers, &pid, &buf_addr, BPF_ANY);
```

توجه کنید که آدرس بافر را به‌عنوان مقدار `u64` ذخیره می‌کنیم.

## خواندن بافر در خروج

حالا در برنامه خروج، باید بافری را که syscall پر کرده گرفته و بخوانیم.

ابتدا بررسی کنید read موفق بوده:

```c
size_t count = ctx->ret;
if (count <= 0) return 0;
```
مقدار بازگشتی `ctx->ret` می‌گوید چند بایت خوانده شده.

بعد، آدرس بافر ذخیره‌شده را با PID به‌عنوان کلید پیدا کنید:
```c
u64 *buf_ptr = bpf_map_lookup_elem(&read_buffers, &pid);
if (!buf_ptr) return 0;
```
این یک اشاره‌گر به مقدار ذخیره‌شده (`u64*`) برمی‌گرداند.

برای خواندن بافر، یک بافر محلی بسازید و از `bpf_probe_read_user` استفاده کنید. باید `buf_ptr` را dereference کنید تا آدرس واقعی بافر را بگیرید:

```c
char local_buf[32];
if (count > 32) count = 32;
bpf_probe_read_user(local_buf, count, (void *)*buf_ptr);
```
به `*buf_ptr` توجه کنید — اشاره‌گر را dereference می‌کنیم تا آدرس بافری که قبلاً ذخیره کردیم را بگیریم.
