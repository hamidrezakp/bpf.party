در تمرین قبلی یاد گرفتید چگونه آرگومان `filename` را از system call `execve` با `ctx->args[0]` بخوانید.

اکنون آرگومان دوم را بررسی می‌کنیم: `argv`. وقتی دستوری مثل این را اجرا می‌کنید:
```bash
./secret_app --password hunter2
```

کرنل آرایه‌ای از آرگومان‌ها دریافت می‌کند:
- `argv[0]` = `"./secret_app"`
- `argv[1]` = `"--password"`
- `argv[2]` = `"hunter2"`
- `argv[3]` = `NULL` (terminator)

با نگاه به [صفحه manual execve](https://man7.org/linux/man-pages/man2/execve.2.html):

```c
int execve(const char *filename, char *const argv[], char *const envp[]);
```

پارامتر دوم، `argv`، در `ctx->args[1]` قرار دارد.

برخلاف `filename` که یک pointer ساده به رشته بود، `argv` و `envp` **pointer به آرایه‌ای از pointerها** هستند.

همان‌طور که در نمودار می‌بینید، `argv` و `envp` با یک pointer NULL خاتمه می‌یابند.

وقتی یک ورودی از آرایه `argv` را می‌خوانید (مثلاً `argv[i]`)، قبل از استفاده بررسی کنید که `NULL` نباشد، چون پایان آرایه را نشان می‌دهد.

## خواندن آرایهٔ اشاره‌گرها

برای خواندن `argv` باید:

1. pointer argv را از `ctx->args[1]` بگیرید
2. آن را از `unsigned long` به `char **` cast کنید
3. هر pointer در آرایه را از **فضای کاربر** بخوانید
4. برای هر pointer، رشته‌ای که به آن اشاره می‌کند را هم از **فضای کاربر** بخوانید

ساختار پایه به این شکل است:

```c
// Get the argv pointer
char **argv = (char **)ctx->args[1];

// In a loop, read the next pointer from the array
char *arg_ptr;
bpf_probe_read_user(&arg_ptr, sizeof(arg_ptr), &argv[i]);
// Remember to check for the NULL terminator!

// Read the string that pointer points to
char arg_buf[64];
bpf_probe_read_user_str(arg_buf, sizeof(arg_buf), arg_ptr);
```

به یاد داشته باشید حلقه باید حد بالای ثابت داشته باشد (مثل `i < 10`) چون verifier باید اثبات کند برنامه شما خاتمه می‌یابد.

## صورت تمرین

یک برنامه مشکوک با flag `--password` و سپس رمز عبور واقعی اجرا می‌شود.

باید:

1. در آرایه `argv` iterate کنید (iteration را به ۱۰ آرگومان محدود کنید)
2. آرگومانی که شامل `"--password"` است را پیدا کنید
3. **آرگومان بعدی** را بخوانید که رمز عبور واقعی را دارد
4. آن را با `SUBMIT_STR_LEN` ارسال کنید
