وقتی یک برنامه eBPF اجرا می‌شود، در **فضای کرنل** اجرا می‌شود، اما به اطلاعاتی درباره پردازه‌ای که رویداد را فعال کرده دسترسی دارد.

مثلاً اگر `bash` یک رویداد را فعال کند، برنامه eBPF شما می‌تواند جزئیات context پردازه `bash` را بپرسد: نام، شناسه پردازه (PID) و موارد دیگر.

کرنل یک [مجموعه بزرگ از توابع helper](https://docs.ebpf.io/linux/helper-function/) برای دریافت این اطلاعات درباره پردازه فعال‌کننده تعریف کرده است.

## صورت تمرین

می‌خواهیم نام هر برنامه‌ای که در سیستم اجرا می‌شود را استخراج کنیم.

برای این کار باید کدمان را به رویدادی متصل کنیم که هر بار یک برنامه اجرا می‌شود فعال شود.
این رویداد `sched_process_exec` نام دارد.

در snippet از پیش بارگذاری‌شده، تعریف «section» خاصی را درست بالای تابع می‌بینید:

```c
SEC("tp/sched/sched_process_exec")
```
این ماکرو به loader eBPF می‌گوید تابع را به آن tracepoint مشخص متصل کند.
اکنون هر بار scheduler یک پردازه جدید اجرا کند، کد ما هم اجرا می‌شود!


**snippet از پیش بارگذاری‌شده را الان اجرا کنید.** باید برای هر رویداد یک ورودی log کند.

### دریافت نام برنامه

کد نمونه کار می‌کند، اما یک رشته ثابت چاپ می‌کند. ما نام واقعی برنامه را برای هر اجرا می‌خواهیم.

چون کد ما به اطلاعات پردازه جدید دسترسی دارد، می‌توانیم از کرنل نام پردازه فعال‌کننده را بپرسیم.

از [bpf_get_current_comm(&buf, size)](https://docs.ebpf.io/linux/helper-function/bpf_get_current_comm/) استفاده می‌کنیم
که نام پردازه فعلی را در بافری که شما فراهم می‌کنید می‌نویسد.

در C می‌توانیم یک بافر کاراکتر تعریف کنیم:
```c
char buffer[16];
```

برای پر کردن بافر با نام پردازه فعلی، تابع helper را فراخوانی کنید:

```c
bpf_get_current_comm(&buffer, sizeof(buffer));
```

سپس `DEBUG_STR` را برای دیدن نتیجه فراخوانی کنید:

```c
DEBUG_STR("Command", buffer);
```

**الان این را امتحان کنید**. برنامه‌های عادی مثل `ls` را می‌بینید و یکی که متمایز است.

### مقایسهٔ رشته‌ها

برای فیلتر کردن ورودی‌های ناخواسته باید رشته‌ها را مقایسه کنید.

از [bpf_strncmp(s1, s1_sz, s2)](https://docs.ebpf.io/linux/helper-function/bpf_strncmp/) استفاده می‌کنیم
که یک رشته متغیر را با یک رشته ثابت مقایسه می‌کند.

مثلاً برای بررسی اینکه بافر شامل `"ls"` است:

```c
if (bpf_strncmp(buffer, sizeof(buffer), "ls") == 0) {
    // buffer contains "ls"
}
```

وقتی رشته‌ها **match** باشند **0** برمی‌گرداند.

### کاری که باید انجام دهید

نام برنامه‌ای که متمایز است را با `SUBMIT_STR(buffer)` ارسال کنید.
