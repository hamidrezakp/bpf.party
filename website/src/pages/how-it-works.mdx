هنگام نوشتن کد، [TCC (Tiny C Compiler)](https://bellard.org/tcc/) در مرورگر شما از طریق WASM اجرا می‌شود تا typechecking فوری بدون roundtrip سرور فراهم شود.

وقتی روی «اجرا» کلیک می‌کنید، کد شما در local storage ذخیره و به بک‌اند ارسال می‌شود.

بک‌اند کد شما را با `clang` به یک شیء BPF کامپایل می‌کند و یک VM تازه برای اجرای آن بالا می‌آورد..

## ماشین مجازی

هر ارسال یک VM موقت با موارد زیر دریافت می‌کند:

- نیم vCPU و ۶۴ مگابایت RAM
- هستهٔ Linux 6.18.2
- بدون دسترسی به شبکهٔ خارجی
- توقف خودکار پس از ۵۰۰ میلی‌ثانیه

زمان بوت ۴۰~۵۰ms است به لطف Firecracker (با چند patch عجیب!) و یک کرنل بسیار minimal.

VM با یک process سفارشی `/init` بوت می‌شود که حداقل راه‌اندازی را انجام می‌دهد (mount کردن `/sys`، راه‌اندازی loopback و ...)، شیء BPF شما را load می‌کند و eventها را stream می‌کند.

## دریافت رویدادها از ماشین مجازی

کد شما باید `ep_platform.h` را `#include` کند که یک map از نوع BPF ringbuf برای همه خروجی‌ها ایجاد می‌کند.

ماکروهای `DEBUG_` و `SUBMIT_` eventها را در این map می‌نویسند.

داخل VM، process init این ringbuf را poll می‌کند و eventها را از طریق [vsock](https://man7.org/linux/man-pages/man7/vsock.7.html) به host forward می‌کند. بک‌اند این eventها را از طریق SSE به مرورگر شما stream می‌کند.
